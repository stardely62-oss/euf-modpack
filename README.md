# Сборка euf

Сборка модов для **Minecraft 1.21.1 (NeoForge)**: наши моды и всё, что с ними играется вместе. Ставится и обновляется одним файлом в TLauncher, лицензия Minecraft не нужна.

## Что внутри

| Мод | Что делает | Откуда |
|---|---|---|
| [Mage's Legacy](https://github.com/stardely62-oss/mages-legacy) | легенда о безымянном маге и выбор одной из восьми рас. Пробуждены Пустотники, Мицелиды и Кровники, остальные расы пока спят | наш, GitHub Releases (`neo-dev`) |
| [Veil](https://modrinth.com/mod/veil) | шейдеры, свечение и постобработка для эффектов Mage's Legacy (несовместим с Embeddium/Rubidium) | Modrinth, 4.5.2 |
| [GeckoLib](https://modrinth.com/mod/geckolib) | анимированные 3D-модели для эффектов | Modrinth, 4.9.3 |

Точный список с версиями лежит в [`modpack.json`](modpack.json). Установщик берёт его отсюда при каждом запуске, так что новые моды сборки приходят сами.

## Установка (TLauncher)

1. В TLauncher выбери **NeoForge 1.21.1** (21.1.217 или новее) и запусти один раз до главного меню.
2. Скачай [`euf-modpack.zip`](https://github.com/stardely62-oss/euf-modpack/releases/latest/download/euf-modpack.zip), распакуй куда угодно и запусти `install-modpack.bat`.
3. Запускай в TLauncher ту версию NeoForge, которую назовёт установщик.

Для обновления запусти `install-modpack.bat` ещё раз: он докачает новые версии и уберёт старые. Моды прежней сборки на Fabric 1.20.1 (Ender Obelisks, Fabric API) и JourneyMap, который из сборки убран, он тоже удаляет, если найдёт их в папке модов.

> Переходишь со старой сборки на Fabric 1.20.1? Скачай новый `euf-modpack.zip`: старый установщик умеет ставить только в Fabric.

Параметры (для `install.ps1`):
- `-Stable` — стабильные релизы наших модов вместо свежих dev-сборок;
- `-VersionName "…"` — конкретная версия в TLauncher (по умолчанию установщик сам находит NeoForge 1.21.1);
- `-GameDir "…"` — другая папка игры.

## Клавиши

**Mage's Legacy:** **K** — легенда и выбор расы, а после выбора — дерево талантов. Способности: **R**, **V**, **H**; Пробуждения: первое на **Z**, второе на **левом Alt**.

| Раса | R | V | H | Z / Alt (Пробуждения, два из трёх) |
|---|---|---|---|---|
| Пустотники | Пустотный шаг (с 3 ур.; Shift+R — метка, если изучена) | Повышенная гравитация (с 5 ур.) | Карман (с 1 ур.) | Разлом пространства / Сквозь миры (Shift — запомнить место) / Чёрная дыра |

## Для разработки

Чужие моды не хранятся в репозитории: установщик качает их с Modrinth и сверяет контрольную сумму. Чтобы добавить мод, допиши его в `modpack.json`:
- для нашего мода — `github`, маску `asset` и при необходимости `devTag` (тег dev-релиза, по умолчанию `dev`);
- для чужого — `url`, `file` и `sha512` с Modrinth (только файлы для NeoForge 1.21.1).

`replaces` — какие старые файлы мода убрать при обновлении; `remove` на верхнем уровне — файлы, которые нужно убрать совсем (моды, ушедшие из сборки).

Ender Obelisks и сборка на Fabric 1.20.1 больше не поддерживаются.
